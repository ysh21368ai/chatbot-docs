# 사용자 매뉴얼 (운영)

장금상선 그룹 챗봇 **운영 서비스**의 사용자 안내서입니다. 운영 서비스는 **팀 단위로 격리된 문서 RAG 챗봇**으로, 아래 4가지 기능을 제공합니다.

> 워크플로·스킬·도구 연결·Claude Code 같은 실험 기능은 **개발 환경 전용**이며 운영 서비스에는 없습니다(ADR-0009). 개발 기능 문서는 "개발자 문서" 섹션을 참고하세요.

## 1. 채팅 — 질문하고 답 받기

- 위치: `/chat` (로그인 후 첫 화면)
- 입력창에 질문을 적고 Enter 로 전송합니다. Shift+Enter 는 줄바꿈, `/` 입력 시 빠른 명령 메뉴가 열립니다.
- 답변은 실시간 스트리밍으로 표시되고, 생성 중에는 중지(■) 버튼으로 끊을 수 있습니다 — 그때까지 받은 내용은 보존됩니다.
- **첫 화면이 곧 챗봇 선택 화면입니다.** 가운데 카드에서 쓰고 싶은 챗봇을 고르면 그 챗봇과 대화가 시작됩니다(카드가 많으면 검색창으로 좁힐 수 있습니다). 이미 대화 중이라면 **상단의 챗봇 칩**을 눌러 즉시 바꿀 수 있습니다.
- 챗봇은 연결된 회사 문서를 근거로 답하며, 답변에 `[출처N]` 뱃지가 붙습니다. 클릭하면 원문 문서 뷰어가 열립니다.
- 쓸 수 있는 챗봇이 없으면 `① 문서 올리기 → ② 챗봇 만들기` 안내가 표시됩니다 — 챗봇은 근거로 쓸 문서가 있어야 의미가 있기 때문입니다.
- 모델은 최고 성능 모델 하나로 고정되어 있어 따로 고를 필요가 없습니다.
- **이미지 생성**: "컨테이너선 사진 그려줘" 처럼 요청하면 챗봇이 직접 이미지를 만들어 대화에 보여줍니다(GPT-Image-2). 사내 문서와 무관한 요청도 가능합니다.
- 좌측 사이드바: 대화 목록(검색·이름 변경·삭제), 새 채팅. 대화 옆에 점이 보이면 실행 중(주황) 또는 실패(빨강) 상태입니다 — 정상 완료된 대화에는 점이 없습니다.
- 전송이 실패하면 화면 중앙에 복구 안내가 뜹니다 — 입력한 메시지는 보존되며 즉시 재시도하거나 새 채팅으로 넘어갈 수 있습니다.

## 2. 자료 올리기 — 문서 업로드

- 위치: `/documents`
- PDF · DOCX · PPTX · XLSX · CSV · HWP · MD · TXT 를 드래그앤드롭 또는 클릭으로 업로드합니다.
  - 한 번에 최대 30개 / 파일당 50MB / 합계 150MB.
- 업로드 시 **공개 범위**를 선택합니다: `개인`(나만 — 기본값·권장) / `팀`(팀원 모두 검색·열람). 개인 문서는 목록에서도 다른 팀원에게 보이지 않습니다.
- ⚠️ **팀 문서는 신중하게** — 팀 문서는 팀 전원의 AI 답변에 바로 반영됩니다. 불필요하거나 부정확한 문서(초안·구버전·개인 메모)를 팀으로 올리면 **팀 전체 데이터가 오염되어 잘못된 답변**이 나갈 수 있습니다. 검증된 공식 자료(최신 규정·매뉴얼·공지)만 팀 문서로 올리고, 그 외에는 개인 문서를 사용하세요.
- 폴더로 정리할 수 있습니다 — 좌측 폴더 트리에서 문서를 드래그해 옮기고, 폴더에 마우스를 올리면 **이름 변경·삭제**가 가능합니다(폴더를 삭제해도 안의 문서는 지워지지 않고 ‘미분류’로 이동합니다). 파일별 설명은 업로드 후 자동 요약으로 채워지며 직접 수정할 수 있습니다.
- 업로드 직후 자동으로 검색 인덱싱(청크·임베딩)이 진행됩니다 — 목록의 ‘처리 중’ 배지가 사라지면 챗봇이 인용할 수 있습니다. 실패 시 배지에 사유가 표시됩니다.

## 3. 챗봇 만들기 — 반복 업무를 봇으로

- 위치: `/chatbots`
- 이름·설명·시스템 프롬프트(역할 지시)·모델을 정해 팀 전용 챗봇을 만듭니다.
- **가시성**: `나만` / `우리 팀` / `선택 팀`. 팀 가시성 챗봇은 팀원 모두 채팅 화면에서 선택해 사용할 수 있습니다.
- **문서 연결**: 챗봇에 RAG 문서 묶음을 지정하면 그 챗봇은 항상 해당 문서를 근거로 답합니다.
- 챗봇별 Q&A 게시판은 **추후 버전에서 제공 예정**입니다(현재 운영 화면에는 없음). 전역 질문/기능 요청은 아래 `/faq` 게시판을 이용하세요.

## 4. 문서 검색 (RAG) — 어떻게 동작하나

- 질문하면 팀 문서에서 의미(벡터)·키워드 검색을 동시에 수행해 관련 청크를 찾고, 그 근거로 답변을 생성합니다.
- 권한은 항상 강제됩니다 — **다른 팀 문서, 다른 사람의 개인 문서는 검색 대상에서 제외**됩니다.
- 답변의 `[출처N]` 을 클릭하면 해당 문서의 원문 위치로 이동합니다. 출처가 없는 일반 지식 답변과 구분해 주세요.

## 자주 묻는 질문

**클로드 코드(Claude Code) 기능을 챗봇에서 호출할 수 있나요?**
아니요. 클로드 코드 모드·코드 실행·도구 마켓·워크플로·스킬·스케줄은 개발 환경 전용 기능이라 운영 서비스에는 없습니다. 운영 챗봇은 문서 질문·답변(RAG), 파일 산출물(Word·Excel·PPT·PDF), 차트, 이미지 생성, 주가 조회, 웹 검색을 제공합니다.

**답변을 파일로 받을 수 있나요?**
네. "엑셀로 만들어줘", "워드로 뽑아줘", "PPT로 정리해줘"라고 하면 답변 아래 파일 카드가 생기고 뷰어에서 내려받습니다. 서식(제목·헤더 색·테두리·열 너비·쪽번호)은 자동이고, "합계 행도 넣어줘", "막대 차트도"처럼 말하면 엑셀에 반영됩니다.

**차트나 이미지는요?**
"차트로 그려줘"는 표 데이터를 차트 이미지로, "이미지 만들어줘"는 주제에 맞는 비율(가로·세로·정방형)로 이미지를 생성합니다. 둘 다 카드를 눌러 크게 보고 내려받을 수 있습니다.

**내 대화를 누가 볼 수 있나요?**
최종관리자는 구성원별 대화를 볼 수 있습니다. 팀이 만든 **팀 공개** 챗봇에서 오간 대화는 그 팀 구성원이 챗봇별로 볼 수 있습니다. 개인용으로 만든 챗봇의 대화는 만든 사람만, 최종관리자가 만든 전사 공개 챗봇(예: 마음쉼터)의 대화는 최종관리자만 봅니다.

**해외 법인인데 화면이 한국어예요.**
우측 상단 언어 선택에서 바꾸면 메뉴·버튼이 번역됩니다. 대화 본문은 번역하지 않으니 원하는 언어로 질문하세요.

**답변이 틀렸거나 문서를 못 찾아요.**
답변의 [출처N]을 눌러 근거 문단을 확인하고, 문서가 없으면 팀의 자료 올리기로 추가하세요. 그래도 이상하면 물어보기 게시판에 화면 캡처와 함께 남겨 주세요.

## 언어 (해외 법인)

- 화면 오른쪽 위 **언어 선택기**에서 17개 언어로 즉시 바꿀 수 있습니다 — 简体中文 · 繁體中文 · 日本語 · Tiếng Việt · ไทย · Bahasa Indonesia · Bahasa Melayu · हिन्दी · বাংলা · සිංහල · ភាសាខ្មែរ · မြန်မာ · Русский · Türkçe · العربية · English.
- 선택한 언어는 계정에 저장돼 다른 기기에서도 그대로 열립니다. 로그인 전 화면에서도 바꿀 수 있습니다.
- 언어를 바꾸면 **챗봇 답변도 그 언어로** 나옵니다. 근거가 되는 사내 문서는 한국어 원문 그대로이며, 조항 번호·금액·날짜·회사명·파일명은 원문 표기를 유지합니다.
- ⚠️ 번역은 기계 번역입니다. **규정 해석의 기준은 한국어 원문**이며, `[출처N]` 을 눌러 원문을 확인할 수 있습니다.
- 아랍어를 선택하면 화면이 오른쪽에서 왼쪽(RTL)으로 정렬됩니다.

## 계정

- **로그인**: 회사 이메일 또는 **그룹웨어 아이디** + 비밀번호로 로그인합니다. 전 직원 계정은 인사 시스템과 매일 자동 동기화되어 미리 등록돼 있으므로 별도 가입이 필요 없습니다(운영은 자체 회원가입이 꺼져 있음). 사내 포털에서 넘어오는 경우 자동 로그인(SSO)됩니다.
- 로그인 상태는 사용 중이면 자동 연장됩니다(액세스 60분 + 자동 갱신 14일). 만료되면 로그인 화면으로 돌아갑니다.
- 이름 변경: `/mypage`. 비밀번호를 잊었다면 관리자에게 초기화를 요청하세요.

## 관리자 참고

- 팀장(team_admin)은 공지 작성, FAQ 답변/상태 관리, 팀 멤버 승인·역할 관리(`/admin`), 팀 활동 기록(`/team`)을 사용할 수 있습니다.
- 저장 용량 쿼터는 `/admin` 의 팀 설정에서 관리합니다(GB 단위).

## 파일 산출물

### 파일로 받기 (Word·Excel·PPT·PDF)

"이 내용을 엑셀로 만들어줘", "리포트를 워드로 뽑아줘", "PPT 로 정리해줘" 처럼 말하면 답변 아래에 파일 카드가 생기고, 카드를 누르면 오른쪽 뷰어에서 내용을 확인하고 내려받을 수 있습니다.

- **서식은 자동**입니다. 엑셀은 제목행·색이 있는 헤더·테두리·줄무늬·열 너비·틀 고정·자동 필터·숫자 서식이 적용되고, 워드는 제목·머리말 스타일·목록·표 스타일·쪽번호가 들어갑니다. PPT 는 제목 슬라이드와 절별 슬라이드로 구성됩니다.
- **더 꾸미고 싶으면 말로 요청**하세요. "합계랑 평균 행도 넣어줘", "막대 차트도 같이", "초록색 테마로" 같은 요청이 엑셀에 반영됩니다.
- **형식만 바꾸고 싶으면** "엑셀로", "워드로", "PDF 로" 라고만 해도 직전에 만든 표·문서를 그 형식으로 바로 만들어 줍니다. 도우미가 "다시 만들어 드릴까요?" 라고 물었을 때 "네" 라고 하면 곧바로 실행됩니다.
- 뷰어 상단의 **WORD · PDF · EXCEL · PPT** 버튼으로 같은 내용을 다른 형식으로 바로 받을 수 있습니다.

### 대화 감사 (자기 팀 챗봇)

관리 콘솔 → **대화 감사**에서 **우리 팀 챗봇** 모드를 고르면, 우리 팀이 만든 챗봇 중 **팀에 공개된 것**의 대화를 볼 수 있습니다. 개인용으로 만든 챗봇은 만든 사람 본인만 볼 수 있습니다. 다른 팀 직원이 우리 챗봇에 물은 것도 포함되며 질문자 이름과 소속이 함께 표시됩니다. 챗봇을 고르면 먼저 질문한 사람 목록이 나오고, 사람을 고르면 그 사람의 대화만 모아 봅니다. 답변 품질과 자주 묻는 내용을 파악해 문서를 보강하는 데 쓰세요. 구성원 개인별 전체 대화 열람은 최종관리자만 할 수 있습니다.
